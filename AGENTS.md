# Описание проекта находится в следующих файлах:
* `specifications/gameworld.md` — Игровой мир — что видят игроки (ФЗ)
* `specifications/gameworld_data_model.go` — Модель данных игрового мира (Модель)
* `specifications/technical.md` — Техническая часть — что не видят игроки (ТЗ)

# Рабочие указания
Для этого проекта Go-команды (`go test`, `go build`, `go run`, `go list` и т.п.) всегда запускай с повышенным разрешением Codex, потому что стандартный Go build cache в `%LocalAppData%\go-build` недоступен из песочницы.

Не создавай локальный `server/.gocache`.

`go run` считается запуском сервера, поэтому без явного указания пользователя его не выполнять даже с повышенным разрешением.

# UI Kit и единый визуальный шаблон

Перед любой правкой UI обязательно найди существующий общий UI Kit компонент, общий CSS-шаблон или общий компонент-обёртку.

Если новый или изменяемый элемент относится к уже существующему типу UI — окно, кнопка, вкладка, выпадающий список, поле ввода, список, scrollbar, tooltip, контекстное меню — запрещено делать его отдельной локальной разметкой или отдельным локальным стилем.

Нужно переиспользовать общий источник:
* базовые контролы — `client/src/ui-kit/components.tsx`;
* стили базовых контролов — `.ui-kit-*` в `client/src/style.css`;
* игровые модальные окна — общий оконный каркас, например `.game-window-layer`.

Если общего источника не хватает, сначала расширь общий компонент через props, children или modifier-класс, а затем используй его в конкретном месте.

Для каждого нового общего UI-правила или нового типа общего UI-элемента добавляй тест, который проверяет, что разные места используют один и тот же шаблон, а не локальные копии.
