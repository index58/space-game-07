# Описание проекта находится в следующих файлах:
* `specifications/gameworld.md` — Игровой мир — что видят игроки (ФЗ)
* `specifications/gameworld_data_model.go` — Модель данных игрового мира (Модель). Содержимое этого файла нейросети менять запрещено!
* `specifications/technical.md` — Техническая часть — что не видят игроки (ТЗ)

# Рабочие указания
Для этого проекта Go-команды (`go test`, `go build`, `go run`, `go list` и т.п.) всегда запускай с повышенным разрешением Codex, потому что стандартный Go build cache в `%LocalAppData%\go-build` недоступен из песочницы.

Не создавай локальный `server/.gocache`.

`go run` считается запуском сервера, поэтому без явного указания пользователя его не выполнять даже с повышенным разрешением.

Перед ручными изменениями БД в JSON-файлах, особенно в `server/data/*.json`, нужно проверить, не запущен ли игровой сервер пользователем. Если сервер запущен, его нужно остановить до правок, иначе сервер может затереть ручные изменения своим периодическим сохранением состояния.

Перед созданием любого игрового UI используй локальный скилл из файла .agents\skills\ui-kit-implementation\SKILL.md
