# Описание игрового мира.

## Общее
Компьютерная игра.
Браузерная.
Многопользовательская онлайн ПВЕ/ПВП.
2D. Космос. Вид сверху.
Пространство космоса бесконечно во все стороны.
Основную камеру можно приближать (zoom in) и удалять (zoom out).
Если игрок заходит в игру первый раз, то ему автоматически создаётся персонаж.
В каждый момент времени игрок может играть от лица только одного из своих персонажей.
Для своего нового персонажа игрок выбирает стартовый космический корабль (один из самых маленьких).
Выбранный стартовый космический корабль достаётся новому персонажу даром и становится его собственностью.  

Далее игрок (персонаж под управлением игрока) может:
- летать на корабле по космосу,
- покупать и продавать товары у НПС,
- обмениваться с другими игроками,
- добывать ресурсы,
- строить космические станции,
- строить космические корабли,
- изготавливать ресурсы и предметы,
- изучать схемы и чертежи,
- воевать с НПС,
- воевать с другими игроками,
- подбирать лут НПС,
- подбирать лут игроков.

Всё пространство космоса делится на зоны двух типов:
- ПВЕ (игроки не могут нанести урон друг другу)
- ПВП (игроки могут нанести урон друг другу)

Первая ПВЕ-зона является кругом с центром в центре космоса (в точке с координатами 0:0) и радиусом 100 километров.
Каждая следующая зона является кольцом, начинающимся от внешнего края предыдущей зоны и заканчивающимся на 10 километров дальше от центра космоса.
Зоны чередуются: после ПВЕ идёт ВПВ, а после ПВП идёт ПВЕ.

## Терминология

`Включенный` — подключенный к электрической сети (но не обязательно выполняющий свою работу).  
`Активный` — выполняющий свою работу (если включен в сеть).  
`Объект` — космический объект.

## Космический объект и предмет
Все игровые сущности можно разделить на 2 вида:
- Космические объекты
- Предметы

Космические объекты видны и в космосе и в UI, а предметы видны только в UI.
Предметы могут находиться только внутри какого-то космического объекта.

## Внешний вид и физическое тело космического объекта

Внешний вид космического объекта на экране — это то как выглядит текстура этого объекта в PNG-файле.
Физическое тело космического объекта на экране не видно, а используется для расчётов столкновений и попаданий.
Физическое тело имеет форму выпуклого многоугольника, построенного по точкам, лежащим на эллипсе, вписанном в прямоугольник с размерами, получающимися по формуле:
```
BodyLength = TextureBodyLength * TextureScale // длина прямоугольника
BodyWidth = TextureBodyWidth * TextureScale // ширина прямоугольника
```

## Движение космического объекта
Космические объекты можно разделить на 2 типа:
- Движимые (Корабль, Снаряд, Луч)
- Недвижимые (Станция, Астероид, Лут)

### Силы тяги
Космический корабль приводится в движение силами тяги всех включенных двигателей этого корабля.

У каждого двигателя есть 6 сил тяги:
- Продольная (вперёд/назад),
- Поперечная (вправо/влево),
- Крутящая (по часовой стрелке/против часовой стрелки),

Активная сила тяги работает на 100%, неактивная — на 0%.
Игрок может активировать/деактивировать каждую из этих сил только у всех сразу включенных двигателей.
Активация/деактивация каждой из этих сил может быть назначена либо на нажатие/отжатие клавиши клавиатуры или мыши, либо на начало/окончание движения мыши в одну из 4 сторон: вверх, вниз, вправо, влево.
Все эти силы тяги могут быть активированы одновременно.

По умолчанию настройки следующие:
- Продольная вперёд — клавиша W,
- Продольная назад — клавиша S,
- Поперечная вправо — клавиша D,
- Поперечная влево — клавиша A,
- Крутящая по часовой стрелке — движение мыши вправо,
- Крутящая против часовой стрелки — движение мыши влево.

### Столкновения
Космические объекты сталкиваются своими физическими телами (многоугольниками).
Столкновение влияет на координаты только движимого объекта.
Столкновение влияет на угол поворота только вращаемого объекта.

## Нахождение персонажа внутри космического объекта
Персонаж в игре всегда находится в одном из космических объектов.  
Персонажа в игре не видно и не слышно нигде и никогда.  
Но в будущих версиях возможно он будет появляться.  

Существует 2 вида космических объектов, внутри которых может находиться персонаж:
- Космический корабль
- Космическая станция

Внутри собственного космического объекта персонаж может находиться:
- В кабине пилота
- В хозяйственном отсеке
- В пассажирском кресле  

Внутри чужого космического объекта персонаж может находиться:
- В пассажирском кресле

### Кабина пилота
Кабина пилота есть только в космическом корабле.
Если персонаж находится в кабине пилота, то основная игровая камера следует за пилотируемым кораблём так,
что корабль всегда находится в центре нижней половины экрана носом строго вверх экрана.

В кабине пилота можно:
- Управлять движением космического корабля
- Стрелять из оружия космического корабля
- Подбирать лут с помощью специального оборудования космического корабля
- Добывать ресурсы с помощью специального оборудования космического корабля
- Сканировать пространство радаром космического корабля

В кабине пилота есть панель, на которой по горизонтали в один ряд расположены квадратные клетки.
Каждая из этих клеток может быть назначена пусковой кнопкой для выбранной модели оборудования этого корабля.
При нажатии на такую пусковую кнопку, все включенные единицы оборудования этой модели выполняют своё основное действие.
Например: всё включенное оружие этой модели стреляет, все включенные буры этой модели бурят, все включенные радары этой модели сканируют пространство.

### Хозяйственный отсек
Хозяйственный отсек есть и в космическом корабле и в космической станции.
Если персонаж находится в хозяйственном отсеке, то основная игровая камера расположена так,
что космический объект всегда находится в центре экрана.

В хозяйственном отсеке доступно:
- Управление оборудованием через панель управления оборудованием
- Строительство объектов с помощью роботов
- Производство предметов на специальном оборудовании с помощью роботов
- Ремонт объектов с помощью роботов
- Разбор объектов на части с помощью роботов
- Установка оборудования на объект
- Изучение технологий производства и технологий строительства (нужна лаборатория)

### Пассажирское кресло
Пассажирское кресло может быть только в космическом корабле.
Если персонаж находится в пассажирском кресле, то основная игровая камера расположена так, что космический объект всегда находится в центре экрана.

## Пользовательский интерфейс
Пользователь может находиться на сайте игры в одном из двух режимов:
1) сайтовый (сайт доступен, игра недоступна),
2) игровой (игра доступна, сайт недоступен).

Для входа в игровой режим, нужно кликнуть мышью на игровой экран, расположенный на странице сайта.
После этого обычный курсор мыши станет заблокирован (Pointer Lock), и сайт станет недоступен.
Но игра станет доступна — появится игровой курсор мыши, и начнут работать обработчики клавишных нажатий и перемещений мыши.
Для выхода из игрового режима в сайтовый, нужно нажать на клавиатуре клавишу Escape.

Сайтовый пользовательский интерфейс описан в отдельном документе.
Здесь описан только игровой пользовательский интерфейс (находящийся внутри игрового экрана).
Далее словом "экран" будет обозначен игровой экран.

На экране могут быть следующие панели:
- Панель основных показателей посещаемого объекта (в левой нижней части экрана)
- Мини-карта (в правой нижней части экрана)
- Панель инструментов пилота (в центральной нижней части экрана)
- Чат (в левой центральной части экрана)
- Информационная панель (в правой центральной части экрана)
- Основная всплывающая панель (почти на весь экран, поверх всего, содержит разные вкладки: Карта, Панель управления объектом)

### Панель основных показателей посещаемого объекта
Содержит показатели:
- Очки здоровья (HP / MaxHP)
- Расход энергии (ConsumingPower / GeneratingPower)
- Запас топлива (FuelCount / MaxFuelCount)

### Мини-карта
В верхней части содержит компас линейной формы по горизонтали.  
В левой части содержит значки, расположенные вертикально:
- ПВЕ/ПВП (если ПВЕ, то горит зелёным, если ПВП, то горит красным)
- Якорь (если якорь активен, то он горит белым, а если не активен, то серым)

В основной части содержит прямоугольную область карты, на которой точками отмечены объекты (только станции, корабли, астероиды и свой лут):
- Красным цветом — станции и корабли НПС-кланов
- Жёлтым цветом — станции и корабли других игроков
- Синим цветом — астероиды
- Зелёным цветом — свои станции, корабли и лут
- Светло-серым цветом — станции и корабли без владельца-персонажа и без владельца НПС-клана

### Панель инструментов пилота
Содержит 10 квадратных ячеек, расположенных в один ряд по горизонтали.
На каждую из этих ячеек может быть назначен один из `инструментов пилота` космического объекта.
`Инструмент пилота` — это все находящиеся на объекте единицы оборудования одной модели, имеющей `действие для пилота`.
Выбранным может быть только один `инструмент пилота` (только одна из 10 ячеек).
При активации пилотом основного действия, выбранный `инструмент пилота` выполняет своё `действие для пилота`.

На этой же панели инструментов пилота расположен прогресс-бар заполненности магазина выбранного инструмента пилота.
Если у выбранного инструмента пилота нет магазина, то этот прогресс-бар не отображается.
При наличии магазина этот прогресс-бар отображает, какая часть магазина заполнена.

### Чат
Прямоугольная область, внизу которой строка ввода, а во всей остальной части — сообщения игроков.
Более поздние сообщения расположены ниже.
У чата три режима:
1) Виден полностью, вместе со строкой ввода
2) Виден только текст сообщений, без фона
3) Не виден

### Информационная панель
Автоматически появляется и показывает информацию о космическом объекте, рядом с которым остановился и простоял 3 секунды игрок на своём корабле.
Показывает:
- Название (если не пустое)
- Название модели
- Ник аккаунта персонажа-владельца (если есть)
- НПС-клан-владелец (если есть)
- Список ресурсов с количеством, содержащихся в астероиде (если это астероид)

### Основная всплывающая панель
Имеет размер почти на весь экран. Перекрывает весь остальной пользовательский интерфейс.
Появляется и скрывается нажатием клавиши, выбранной в настройках для любой из её вкладок.
Вкладки:
- Карта
- Инструменты пилота
- Оборудование
- Склад
- Схемы
- Чертежи

#### Карта
Показывает то же самое, что основная часть мини-карты, только на большей территории.
В правом верхнем углу показывает текущие координаты посещаемого объекта.
Колёсиком мыши можно делать приближение и удаление (менять масштаб карты).
Указателем мыши можно двигать пространство космоса, нарисованное на карте, для просмотра других территорий.

#### Инструменты пилота
Показывает список моделей оборудования, являющихся инструментами пилота.
Позволяет менять местами элементы списка для соответствующего изменения их положения на панели инструментов пилота.

#### Оборудование
Имеет две под-вкладки
- Список
- Блок управления

##### Список
Показывает список моделей установленного оборудования: одна модель — один элемент списка.

##### Блок управления
Показывает специальный для выбранной модели оборудования набор элементов управления. В этом наборе обязательно есть:
- Переключатель "Включено" (Enabled), включающий или выключающий всё оборудование этого элемента списка.
- Поле для ввода количества включенных единиц этого оборудования (EnabledCount). Минимум 1, максимум Count.
